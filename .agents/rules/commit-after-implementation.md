# Git Commit After Implementation

After completing any code or configuration implementation in this repository:

1. Verify the changes (run relevant lint/build/test checks).
2. Review `git status` and `git diff` to ensure no unintended, temporary, or generated debug files (such as `.taste-skill/` artifacts or local logs) are included.
3. Stage the implementation files and create a git commit with a clear, helpful commit message summarizing what changed and why.
4. Do not push to a remote unless explicitly asked.
