# instant-nav rig: terraco-website (Angular SSR + Prerendering + View Transitions)

- BUILD: `npm run build && npm run start -- --port ${PLAYWRIGHT_PORT:-3100}` (managed by `playwright.config.ts` `webServer`; runs `ng build` in `apps/web-seo` and launches the Express/Angular SSR server from `apps/web-seo/dist/web-seo/server/server.mjs`)
- ARCHITECTURE: Angular (latest stable) Standalone, Zoneless (`provideZonelessChangeDetection()`), Signals-first, Hybrid SSR + Static Prerendering (`RenderMode.Prerender` in `apps/web-seo/src/app/app.routes.server.ts`), Incremental Hydration (`withEventReplay()`, `withIncrementalHydration()`), and Angular Router View Transitions (`withViewTransitions()`, `withComponentInputBinding()`, `withPreloading(PreloadAllModules)`)
- RUN: `PLAYWRIGHT_PORT=3105 npm run test:e2e -- --workers=1` (sets `baseURL` to `http://localhost:3105` in `playwright.config.ts`; also accepts `PLAYWRIGHT_BASE_URL`)
- TEST USER: public; no authentication; state: static in-memory `LANCAMENTOS` catalog (`prime-view`) managed via Signals in `LancamentosService` (`apps/web-seo/src/app/core/lancamentos.service.ts`), locale `pt-BR`
- DRIFT: none known; catalog data is deterministic in `apps/web-seo/src/app/core/lancamentos.data.ts` and `getPrerenderParams()` in `apps/web-seo/src/app/app.routes.server.ts` prerenders `/`, `/lancamentos`, and `/lancamentos/prime-view` at build time
- CONTRACTS:
  - Initial hard loads (`/`, `/lancamentos`, `/lancamentos/prime-view`): Served immediately from build-time prerendered static HTML with full App Shell (`NavbarComponent`, `FooterComponent`), layered architectural SVG hero (`HeroSvgPrototypeComponent`), SEO metadata (`<title>`, OpenGraph, canonical, JSON-LD `RealEstateListing` + `BreadcrumbList`), and zero loading skeletons (`Carregando lançamento` count = `0`)
  - `/lancamentos` CTA link `"Conhecer lançamento"` (`routerLink="/lancamentos/prime-view"`) -> `/lancamentos/prime-view`: Instant client-side SPA transition via Angular Router (`window.__terracoSpaMarker` preserved across navigation) with App Shell (`Navbar`, `Footer`) and product title `<h1>Prime View</h1>` rendered synchronously without skeleton state
  - `/lancamentos` card title link `"Prime View"` (`routerLink="/lancamentos/prime-view"`) -> `/lancamentos/prime-view`: Instant client-side SPA transition with App Shell and product title `<h1>Prime View</h1>` rendered synchronously
  - `/lancamentos` card image link `"Conhecer Prime View"` (`routerLink="/lancamentos/prime-view"`) -> `/lancamentos/prime-view`: Instant client-side SPA transition with App Shell and product title `<h1>Prime View</h1>` rendered synchronously
- LOOP: local Angular build (`npm run build`) -> start SSR server (`npm run start -- --port ${PLAYWRIGHT_PORT}`) -> verify via Playwright `webServer` on a dedicated `PLAYWRIGHT_PORT` (stops server on exit) -> edit -> repeat; agent limits: none for local runs
- LIVENESS: n/a; local build and start
- WALLS: Pre-existing server on port `3100` when `reuseExistingServer: !process.env.CI` is active in `playwright.config.ts` can serve a stale build if port `3100` is reused; resolved by setting a fresh `PLAYWRIGHT_PORT=3105` (or stopping the listener on `3100` before running).
